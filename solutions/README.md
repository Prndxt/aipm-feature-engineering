# Solutions

The three notebooks, solved and run, with sample answers to every 🧠 question. Try first, then compare your reasoning, not just your numbers.

| File | Description |
|---|---|
| [**1 - Shape the Data**](1_shape_the_data.ipynb) | Split, gaps, imputation, encoding, scalers, log, the model-ready table. |
| [**2 - Snowman Exercise**](2_snowman_exercise.ipynb) | Plan, `X_train_fe` (M1), new rows and the wrap (M2), the pipeline recipe. |
| [**3 - PM Feature Decisions**](3_pm_feature_decisions.ipynb) | Leak hunt, four tests, flags, final test, Belgium, sample feature spec and recommendation. |

> The solution notebooks read the data from `../data/`. Many 🧠 questions have more than one good answer: a different answer with a clear reason is fine.
